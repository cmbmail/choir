# 弦歌合唱团管理系统

合唱团排练、献唱、作业、成员与资料管理平台。**支持多个合唱团（团队）同时使用**，数据按团队隔离；**每团 ≤100 人**，**系统超管** 可创建合唱团、代改任意团团名；**团内超管/指挥** 权限相同（改本团名、成员、发邀请等）；**班长** 仅本团发邀请。新成员仅可通过 **本团邀请码** 注册。数据库：**生产 RDS MySQL**；文件：**CDE**。

### 本地配置密钥

1. 复制 `.env.example` 为 `.env`（已在 `.gitignore` 中，不会提交）
2. 填入 RAM 的 AccessKey ID / Secret（**不要**把密钥发给他人或写进聊天/代码仓库）
3. CDE 的 `DRIVE_ID`、`ENDPOINT` 等阶段二在阿里云盘企业版控制台获取后补全部署于阿里云 ECS（轻量配置即可），数据库使用 **阿里云 RDS MySQL 8.0**（VPC 内网连接），文件存储使用 **阿里云盘企业版 CDE**。
