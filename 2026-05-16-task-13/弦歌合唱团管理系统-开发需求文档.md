## 一、项目概述

### 1.1 项目背景
弦歌合唱团需要一个专业的管理系统，用于管理团员的排练计划、献唱计划、作业提交、成员信息、资料管理、录音管理等核心业务。

### 1.2 项目目标
- 提供极简中式风格的用户界面
- 支持多声部（1-8个声部）管理
- 实现音视频资料的上传、存储、在线播放
- 提供完整的权限管理（6级角色权限）
- 支持50人团队的协作使用
- **支持电脑和手机访问（响应式设计）**

### 1.3 技术选型

| 类别 | 技术 |
|------|------|
| 后端语言 | Python 3.9+ |
| Web框架 | Flask 2.3+ / Django 4.2+ |
| 数据库 | MySQL 8.0 / PostgreSQL 14+ |
| 文件存储 | 阿里云PDS (Personal Drive Service) |
| 部署平台 | 阿里云ECS (Elastic Compute Service) |
| 操作系统 | 阿里云OS (Alibaba Cloud Linux 3) |
| 前端技术 | HTML5 + CSS3 + Vanilla JavaScript |
| 响应式设计 | CSS Media Queries + Flexbox/Grid |
| 在线播放 | HTML5 Audio API |
| 服务器 | Nginx + Gunicorn/uWSGI |

## 三、数据模型设计

### 3.1 ER图（文字描述）

```
[用户] 1──n [排练签到]
[用户] 1──n [作业提交]
[用户] 1──n [录音上传]
[作品] 1──n [录音]
[排练] n──n [曲目]
[演出] n──n [曲目]
[用户] 1──n [操作日志]
```

### 3.2 数据库表设计

```sql
-- 用户表
CREATE TABLE users (
    user_id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    name VARCHAR(50) NOT NULL,
    role ENUM('super_admin', 'conductor', 'class_leader', 'section_leader', 'general_affairs', 'member') DEFAULT 'member',
    voice_part INT,
    phone VARCHAR(20),
    email VARCHAR(100),
    avatar_url VARCHAR(500),
    last_login TIMESTAMP NULL,
    status ENUM('active', 'leave', 'inactive') DEFAULT 'active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_role (role),
    INDEX idx_voice_part (voice_part),
    INDEX idx_status (status)
);

-- 系统配置表
CREATE TABLE system_config (
    config_id INT PRIMARY KEY AUTO_INCREMENT,
    config_key VARCHAR(50) UNIQUE NOT NULL,
    config_value TEXT,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 排练计划表
CREATE TABLE rehearsals (
    rehearsal_id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(100) NOT NULL,
    date DATE NOT NULL,
    start_time TIME,
    end_time TIME,
    location VARCHAR(100),
    conductor VARCHAR(50),
    repertoire JSON,
    attendance JSON,
    created_by INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_date (date),
    FOREIGN KEY (created_by) REFERENCES users(user_id)
);

-- 演出计划表
CREATE TABLE performances (
    performance_id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(100) NOT NULL,
    date DATE NOT NULL,
    location VARCHAR(100),
    type ENUM('internal', 'external'),
    repertoire JSON,
    recording_url VARCHAR(500),
    setlist_url VARCHAR(500),
    created_by INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_date (date),
    FOREIGN KEY (created_by) REFERENCES users(user_id)
);

-- 作业表
CREATE TABLE assignments (
    assignment_id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(100) NOT NULL,
    description TEXT,
    deadline DATETIME,
    files JSON,
    target_voice_parts JSON,
    created_by INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_deadline (deadline),
    FOREIGN KEY (created_by) REFERENCES users(user_id)
);

-- 作业提交表
CREATE TABLE submissions (
    submission_id INT PRIMARY KEY AUTO_INCREMENT,
    assignment_id INT,
    user_id INT,
    files JSON,
    feedback TEXT,
    score DECIMAL(5,2),
    status ENUM('submitted', 'graded') DEFAULT 'submitted',
    submitted_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_assignment (assignment_id),
    INDEX idx_user (user_id),
    FOREIGN KEY (assignment_id) REFERENCES assignments(assignment_id),
    FOREIGN KEY (user_id) REFERENCES users(user_id)
);

-- 资料表
CREATE TABLE documents (
    document_id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(100) NOT NULL,
    type ENUM('score', 'video', 'courseware', 'text', 'audio') NOT NULL,
    file_url VARCHAR(500),
    file_size BIGINT,
    voice_parts JSON,
    uploaded_by INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_type (type),
    INDEX idx_created_at (created_at),
    FOREIGN KEY (uploaded_by) REFERENCES users(user_id)
);

-- 作品表
CREATE TABLE works (
    work_id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    composer VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 录音表
CREATE TABLE recordings (
    recording_id INT PRIMARY KEY AUTO_INCREMENT,
    work_id INT,
    name VARCHAR(100) NOT NULL,
    file_url VARCHAR(500),
    parts JSON,
    uploaded_by INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_work (work_id),
    FOREIGN KEY (work_id) REFERENCES works(work_id),
    FOREIGN KEY (uploaded_by) REFERENCES users(user_id)
);

-- 操作日志表
CREATE TABLE operation_logs (
    log_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id INT,
    action VARCHAR(100),
    details JSON,
    ip_address VARCHAR(45),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user (user_id),
    INDEX idx_created_at (created_at),
    FOREIGN KEY (user_id) REFERENCES users(user_id)
);

-- 系统监控表
CREATE TABLE system_monitor (
    monitor_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    cpu_usage DECIMAL(5,2),
    memory_usage DECIMAL(5,2),
    disk_usage DECIMAL(5,2),
    pds_usage BIGINT,
    online_users INT,
    api_requests INT,
    avg_response_time DECIMAL(10,2),
    INDEX idx_timestamp (timestamp)
);
```

### 5.2 文件上传流程

```python
# services/pds_service.py
from aliyun_python_sdk_pds import PDSClient

class PDSService:
    def __init__(self, config):
        self.client = PDSClient(config)
    
    def upload_file(self, file_obj, file_name, parent_path='/choir'):
        """上传文件到PDS"""
        result = self.client.upload_file(
            drive_id=self.config['drive_id'],
            file_path=f"{parent_path}/{file_name}",
            file_obj=file_obj
        )
        return result['file_id'], result['url']
    
    def get_download_url(self, file_id, expire_seconds=3600):
        """获取临时访问URL（用于在线播放）"""
        return self.client.get_share_link(file_id, expire_seconds)
    
    def delete_file(self, file_id):
        """删除文件"""
        return self.client.delete_file(file_id)
    
    def get_storage_info(self):
        """获取PDS存储空间使用情况"""
        return self.client.get_drive_info(self.config['drive_id'])
```

### 6.2 系统压力监控

```python
# services/monitor_service.py
class MonitorService:
    def get_system_load(self):
        """获取系统压力指标"""
        # 在线用户数（从Redis获取）
        online_users = redis_client.scard('online_users')
        
        # API请求数（最近5分钟）
        api_requests = redis_client.get('api_requests_5min') or 0
        
        # 平均响应时间（最近5分钟）
        response_times = redis_client.lrange('response_times', 0, -1)
        avg_response_time = sum(map(float, response_times)) / len(response_times) if response_times else 0
        
        return {
            'online_users': online_users,
            'api_requests': int(api_requests),
            'avg_response_time': round(avg_response_time, 2)
        }
```

## 十、非功能性需求

### 10.1 性能要求
- 页面加载时间 < 2秒（桌面端和移动端）
- API响应时间 < 500ms
- 支持50并发用户
- 支持50人团队日常使用

### 10.2 安全要求
- 密码使用bcrypt哈希存储
- API接口需JWT认证
- PDS文件访问使用临时URL（1小时过期）
- SQL注入防护（使用ORM）
- XSS防护（输入过滤、输出转义）
- CSRF防护（CSRF Token）
- 操作日志记录所有关键操作

### 10.3 可用性要求
- 系统可用性 > 99%
- 数据每日备份到PDS
- 支持Chrome、Firefox、Safari、Edge（桌面端）
- 支持Safari（iOS）、Chrome（Android）（移动端）

### 10.4 响应式设计要求
- 断点：1200px（桌面）、768px（平板/手机）
- 移动端触摸区域 ≥ 44px
- 移动端字体 ≥ 16px
- 表格在移动端改为卡片式布局
- 侧边栏在移动端改为汉堡菜单
